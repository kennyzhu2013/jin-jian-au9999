# 金鉴

个人用的 Au9999 / 上金所 Au99.99 纸黄金参谋。手机浏览器打开后可以加到主屏幕，离线时仍能看到上次的价格和演示行情。

它会看日线，判断眼下是**趋势**还是**震荡**，只让一边发信号：趋势里跟踪均线和突破，震荡里在区间边缘高抛低吸。信号写明方向、参考价、一句理由和风险。首页上方另有一条**综合建议**，把这个技术状态和黄金相关的政策消息合在一起，给出短线、中线的买入、持有、减仓或卖出。你可以把自己的买卖目标价记在上面。

没有下单，没有券商，也没有账户连接。数字只供自己复盘。

## 本地运行

需要 Node.js 20 以上。

```bash
npm install
npm run dev
```

浏览器打开 [http://127.0.0.1:43123](http://127.0.0.1:43123)。

手机和电脑在同一个局域网时，可以让开发服务器监听所有网卡：

```bash
npm run dev -- --host 0.0.0.0
```

然后用手机浏览器访问电脑的局域网地址，端口仍是 `43123`。服务工作线程只在 `localhost` 或 HTTPS 下注册；用局域网 IP 时，安装提示可能要等你以后把站点放到 HTTPS。

生产构建：

```bash
npm run build
npm run preview
```

预览地址是 [http://127.0.0.1:43124](http://127.0.0.1:43124)。

想在终端里看当前状态和最近几笔信号：

```bash
npm run signals
```

## 装到手机主屏幕

用手机浏览器打开上面的地址。

- iPhone：请用 Safari。点底部分享，选「添加到主屏幕」，名称会显示为「金鉴」。
- Android：请用 Chrome。菜单里选「安装应用」或「添加到主屏幕」。

装好之后它会以独立窗口打开，不带浏览器地址栏。第一次成功打开后，页面外壳会被缓存。之后即使断网，也能打开上次的界面，并显示保存在本机的最近价格。演示行情本身就在应用里，不依赖网络。

## 演示数据

默认是演示模式，不需要密钥。

- `2026-09-09` 至 `2026-10-09` 的开高低收和成交量，摘自当时能核对到的 Au99.99 公开日线。
- 更早的交易日用固定种子补齐，只为了让 30 日均线有样本。K 线上颜色更淡，点开会标「演示补齐」。
- `2026-10-09` 之后没有继续编造。今天如果休市，页面会写「周末休市」或「已收盘」，最近成交仍停在最后一根日线上。

同一份数据也放在 [`public/sample-feed.json`](public/sample-feed.json)。设置里切到「自定义接口」，地址保持 `/sample-feed.json`，就是在走真的请求路径，只是数据还是这份示例。

## 接入真实行情

上海黄金交易所的延时行情页不是给浏览器直接调用的 JSON，页面里也不要写死需要密钥的第三方地址。接法是：你自己准备一个返回 JSON 的地址，填到设置里。

最小可用的响应：

```json
{
  "symbol": "Au99.99",
  "quote": {
    "price": 904.48,
    "open": 892,
    "high": 909,
    "low": 888,
    "prevClose": 892,
    "time": "2026-10-09T15:30:00+08:00"
  }
}
```

只有报价、没有日线时，应用会把价格接到内置样本后面，策略仍然算得出来。更好的做法是连同日线一起给：

```json
{
  "quote": { "price": 904.48, "time": "2026-10-09T15:30:00+08:00" },
  "bars": [
    { "date": "2026-10-09", "open": 892, "high": 909, "low": 888, "close": 904.48, "volume": 8690.32 }
  ]
}
```

`bars` 少于 40 根时，会用演示日线补上更早的缺口。字段也可以用字符串数字。日期接受 `2026-10-09` 或 `2026/10/09`。

接口必须能被浏览器读到：放在本站（例如 `public/` 下的 JSON），或者返回 `Access-Control-Allow-Origin`。密钥放在你自己的转发服务里，不要写进这个前端。

一个 Cloudflare Worker 的形状如下。上游地址要换成你确认可用的行情源，返回前整理成上面的 JSON：

```js
export default {
  async fetch() {
    const upstream = await fetch("https://your-quote-source.example/au9999");
    const raw = await upstream.json();
    return Response.json(
      {
        symbol: "Au99.99",
        quote: {
          price: raw.price,
          open: raw.open,
          high: raw.high,
          low: raw.low,
          prevClose: raw.prevClose,
          time: new Date().toISOString(),
        },
        bars: raw.bars,
      },
      { headers: { "access-control-allow-origin": "*" } },
    );
  },
};
```

失败或断网时，界面会留下上次成功写入本机的价格，并说明现在看到的是缓存。

## 消息与综合建议

综合建议不替换趋势跟踪和高抛低吸。短线主要看当前状态和区间位置，中线主要看均线背景，两边再叠上最近 21 天、且不晚于最后一根日线的消息偏向。

默认是演示消息，不需要密钥。语料写在 `src/data/news.ts`，日期对齐到 `2026-10-09`，覆盖美联储、美元、地缘、中国购金与金饰、上金所成交。同一份数据在构建或启动开发服务器时写入 [`public/sample-news.json`](public/sample-news.json)。

设置里切到「消息接口」，地址保持 `/sample-news.json`，就会走真的请求路径。自定义 JSON 可以是 `{ "items": [ ... ] }`，也可以直接是数组。每条至少要有 `title` 和 `publishedAt`。可选字段：

| 字段 | 含义 |
| --- | --- |
| `summary` | 摘要。没有 `bias` 时，会和标题一起做关键词打分 |
| `source` | 来源名称 |
| `topic` | `fed`、`usd`、`geopolitics`、`china`、`sge`、`other` |
| `horizon` | `short`、`medium`、`both`。缺省按两边都看 |
| `bias` | 大约 -2 到 2。正数利多黄金，负数利空。缺省时用标题和摘要里的关键词 |

示例：

```json
{
  "items": [
    {
      "id": "fed-20261008",
      "publishedAt": "2026-10-08T21:00:00+08:00",
      "source": "宏观",
      "title": "美联储纪要：限制性利率还要维持一段时间",
      "summary": "多数官员认为现在谈降息还早。",
      "topic": "fed",
      "horizon": "medium",
      "bias": -1.3
    }
  ]
}
```

环境变量（见 [`.env.example`](.env.example)）：

- `VITE_NEWS_API_URL`：消息接口的默认地址。不填则是 `/sample-news.json`。
- `VITE_NEWS_API_KEY`：可选。填写后，请求消息接口会带 `Authorization: Bearer <密钥>`。演示模式不使用它。密钥放在本地 `.env`，不要提交进仓库。

消息接口失败时，会留下上次成功的标题；如果还没有缓存，就回到演示语料，并在页面顶部说明。

## 策略写在哪里

规则不写死在文案里，文案是算出来的。

| 文件 | 做什么 |
| --- | --- |
| `src/strategy/params.ts` | 窗口和阈值 |
| `src/strategy/indicators.ts` | 均线、标准差、效率比、布林带 |
| `src/strategy/frame.ts` | 状态切换。效率比 ≥ 0.38 且方向一致才算趋势，≤ 0.30 回到震荡，中间沿用上一状态 |
| `src/strategy/trend.ts` | 趋势：10/30 日均线交叉，或突破近 20 日高点 / 低点 |
| `src/strategy/range.ts` | 震荡：布林带边缘，或近 20 日区间分位进入 18% / 82% |
| `src/strategy/engine.ts` | 只把当前状态对应的那一边记成可执行信号 |
| `src/strategy/outlook.ts` | 技术状态加消息偏向，合成短线 / 中线建议 |
| `src/data/news.ts` | 演示消息，以及接口 JSON 的整理 |
| `src/strategy/digest.ts` | 用同一份结果写晚报 |

参数可以改，改完刷新即可。页面「信号」里能看到当前效率比、两条策略各自的说法，以及最近触发过的买卖。
